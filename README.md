# Kraków Park Explorer Tracker

An interactive web application designed for personal progress tracking in the official **[Odkrywca Krakowskich Parków](https://zzm.krakow.pl/pl/rekreacja/odkrywca-krakowskich-parkow)** program organized by Zarząd Zieleni Miejskiej (ZZM) w Krakowie.

### Features
- **Interactive Leaflet Map**: Displays all 78 official park locations with custom numbered pin markers.
- **Mobile-First Design**: Optimized for smartphones with dedicated list and map tab views.
- **Local Persistence**: Stamp progress is saved directly in your browser's local storage.
- **Search & Filter**: Find parks by name or official booklet number (#1 – #78).
- **Google Maps Directions**: Direct navigation links for every park.
